# Connection-Map — 연결 3D

오픈웹(닥스훈트)과 다크웹(다크초코)을 겹쳐 그리고 두 층 영토 사이 연결을 선으로 잇는 3D 화면 저장소다.
협업 조직 D4rkn3ttz-Collaboration 의 두 팀이 같이 쓴다. 화면 코드와 쓰는 법은 첫 PR(3D 시제품)에서 들어온다.

## 협업 규칙

- 가지는 `feature/영문` 으로 판다. main 에 바로 올리지 않는다
- 커밋 제목은 「작업명_번호」
- PR 은 다른 팀 공동작업자 1명이 확인한 뒤 머지한다(급하면 예외)

## 공개 저장소

이 저장소는 공개다. 열쇠 값 · 기업명 · 피해 조직명을 넣지 않는다.
